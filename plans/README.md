## Findings considered and rejected

- **`PathLease` is process-local, not a cross-process file lock**
  (`persistence` PathLease): still true. Cross-process concurrent writers
  unsupported; sequential single-writer switch is the product rule (evidence
  658). Not a standalone plan.
- **`support_facts` table dormant** (migration 0002, later retired in 0018):
  resolved by schema retirement; not a plan.
- **ClickHouse `connect` does no network round-trip**: by design of the
  official client; Test/health round-trips cover the UX need. Not a bug.
- **Sync/blocking persistence actor + synchronous CH cancellation budget**:
  deliberate, evidence-recorded tradeoffs. Do not "modernize".
- **No clap/arg parsing in the CLI**: intentional for a TUI-first binary;
  revisit only if headless subcommands become a requirement.
